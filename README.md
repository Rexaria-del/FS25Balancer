# FS25 Balancer

Балансирует цены модов Farming Simulator 25: читает характеристики из XML мода, считает честную цену (€ и ₽) и записывает её обратно. Работает офлайн; локальный ИИ (Ollama) — опционально для определения стран.

## Установка
- **Без сборки:** скачай `FS25Balancer.exe` в [Releases](https://github.com/Rexaria-del/FS25Balancer/releases) и запусти.
- **Из исходников:** `pip install -r requirements.txt`, затем `python app.py`.

## Как пользоваться
1. Укажи папку mods и нажми **Сканировать**.
2. Проверь таблицу: страна, ретро, характеристики, новая цена; колонка «Источник» показывает, кем определена страна (словари / память / ИИ / вручную).
3. Нажми **Применить** — бэкап изменённых XML создаётся в `_backup_original_mods`; откат: **Цены → Откатить из бэкапа**.
4. Другу передай цены: **Цены → Экспорт цен**, у друга — **Импорт цен** и «Применить».

## Возможности
- Техника, здания, поля; 177 стран + СССР; ретро-коэффициент.
- Ручные цены, комплектации двигателей, редактор производств, проверка читерных модов.
- Точечная запись ZIP: меняются только XML, моды не пережимаются.
- Интерфейс RU / EN; локальный ИИ (Ollama) по желанию.

## Дорожная карта
- Синхронизация сохранений между игроками для совместной игры в разное время онлайна (обмен и слияние прогресса фермы без общего сервера).

## Сборка exe
`pip install -r requirements-build.txt`, затем `pyinstaller FS25Balancer.spec`.
